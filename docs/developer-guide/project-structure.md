# Project structure

This page lists every file and folder in the repository, with a one-line summary of what each does.

## Top level

| Path | Purpose |
| --- | --- |
| `index.html` | The page markup: home page, top bar and ☰ menu, data blocks, workout, gear, draft and demo panels, status line, every dialog. |
| `package.json` | Scripts (`dev`, `build`, `preview`) and dependencies. |
| `vite.config.ts` | Vite config: relative base (`./`) and a larger chunk-size warning limit. |
| `tsconfig.json` | TypeScript config: strict mode, `noUnusedLocals`, and the `web-bluetooth` and `vite/client` types. |
| `README.md` | Features, browser support, local run instructions and the backend overview. |
| `CLAUDE.md` | Project notes for AI coding assistants: commands, preferences, deployment and the backend. |
| `db/schema.sql` | The database schema, policies, triggers, admin functions, and the riding-together, leaderboard and ghost functions. |
| `.gitignore` | Ignores `node_modules`, `dist` and `.DS_Store`. |
| `public/` | Static files served as-is. See below. |
| `dist/` | Build output. Generated by `npm run build`, and not tracked by git. |
| `docs/` | This documentation library. |

## `public/`

| Path | Purpose |
| --- | --- |
| `public/models/*.glb` | 3D models: landmarks (barn, farmhouse, windmill, diner, water tower, gas station, silos, covered bridge, start/finish gantry) and the rigged rider (`rider.glb`). |
| `public/models/README.md` | What each landmark model is and where it's placed. |
| `public/textures/asphalt.jpg` | Road surface texture. |
| `public/textures/grass.jpg` | Grass detail texture, multiplied over the land colors. |
| `public/images/hero*.jpg`, `hero*.mp4` | The home page hero (still and looping video, with smaller phone versions). |
| `public/images/hero-dog*.jpg`, `hero-dog*.mp4` | The second hero: a pit bull chasing the rider. The home page picks one of the two heroes per visit. |
| `public/icons/` | App icons (192, 512, maskable 512, Apple touch icon, favicon). |
| `public/manifest.webmanifest` | Makes the app installable: name, icons, full-screen display, colours. |
| `public/sw.js` | Service worker: network-first pages, cached build files, models and textures. Never caches Neon. |

## `src/`

| File | Purpose |
| --- | --- |
| `main.ts` | Entry point. Owns the ride state, runs the frame loop, controls the trainer, handles the top bar, ☰ menu and dialogs, saves rides, and wires up sign-in, riding together, ghosts, plans, sound, virtual shifting and drafting. |
| `home.ts` | The home page: hero (one of two, picked per visit), Google and email sign-up, and *Ride without an account*. |
| `drivetrain.ts` | The virtual drivetrain: automatic gears that keep leg speed in step with road speed, the 24 virtual-shifting gears, crank angle and bike rock. |
| `draft.ts` | Drafting: the drag saved at a given gap behind another rider, and the rider just ahead. |
| `ghost.ts` | Replays a past whole-stage ride as a ghost, and formats race times. |
| `sound.ts` | Ride sounds made with Web Audio: wind, tyre hum, freewheel, crowds, beeps, shift clicks and the finish fanfare. |
| `plans.ts` | The training plans and their progress logic. |
| `plansUi.ts` | The training plans dialog. |
| `onboarding.ts` | The three-step first-ride guide. |
| `ridersUi.ts` | The 👥 button and the *Riding now* list. |
| `leaderboardUi.ts` | The 🏆 leaderboard dialog and *Race* buttons. |
| `style.css` | All styles, including the layout for phones. |
| `hud.ts` | The 24 data-block fields, the HUD tiles, and the data-block chooser dialog. |
| `settings.ts` | The `Settings` type, its defaults, and loading and saving to `localStorage`. |
| `stats.ts` | Ride statistics: averages, normalized power, TSS, best efforts (5 s, 1, 5 and 20 min), max values and time in zone. |
| `zones.ts` | Heart-rate and power zone definitions, zone lookup, and the zone bar display. |
| `physics.ts` | The power-to-speed model: gravity, rolling resistance, air drag (reduced in a draft), drivetrain loss and momentum. |
| `course.ts` | The current stage's road: elevation, grade, heading and a cached centerline. |
| `stages.ts` | Built-in stages (Heartland Rollers, Route 66 Flats, Hell of the West, Alpe d'Huez, Stelvio Pass, Mont Ventoux, Col du Tourmalet, Monte Zoncolan), the climb builder, landmark kinds, and the stage list. |
| `profile.ts` | The elevation strip, and the grade-to-color function. |
| `ble/trainer.ts` | Trainer connection: FTMS and Cycling Power, parsing, and the control point (grade with a wind-resistance factor, and target power). |
| `ble/heartRate.ts` | Heart-rate strap connection and parsing. |
| `routes/gpx.ts` | Parses GPX files, and turns a route into a stage. |
| `routes/library.ts` | Saved GPX routes in `localStorage`, and the full stage list (built-in plus uploaded). |
| `workouts/model.ts` | Workout types, expansion into steps, TSS estimation, the ten built-in workouts, and the zone colors. |
| `workouts/player.ts` | Runs a workout: the clock, the current target, the intensity, pause and skip. |
| `workouts/files.ts` | Imports `.zwo`, `.erg` and `.mrc` files, and exports `.zwo`. |
| `workouts/library.ts` | The rider's saved workouts in `localStorage`, and the built-ins. |
| `workouts/graph.ts` | Draws a workout's shape, with the elapsed time and the power trace. |
| `workouts/ui.ts` | The workout library and the workout creator dialogs. |
| `world/world.ts` | The Three.js renderer, lights, cameras, and the per-frame scene update. |
| `world/others.ts` | Other riders and ghosts on the road: models, name tags, lanes, smoothing and passing. |
| `world/terrain.ts` | Ground tiles, height and color, and the scattered trees. |
| `world/road.ts` | Road chunks, distance markers, hairpin plaques, and the finish line. |
| `world/landmarks.ts` | Loads the landmark models and places them along the road. |
| `world/rider.ts` | The bike and rider: a built-in fallback, and the rig that poses the rigged rider (shared model, cloned per rider; frame colours and ghost look). |
| `world/sky.ts` | The sky dome, the mountain ring, and the clouds. |
| `world/noise.ts` | Deterministic noise (value noise and fractal noise), a seeded random generator, and `smoothstep`. |
| `cloud/client.ts` | The Neon client, configured from the default endpoints or `VITE_` variables. |
| `cloud/account.ts` | The signed-in account: session restore, Google sign-in, email sign-up and sign-in, password reset, sign-out and rename. |
| `cloud/emailAuth.ts` | The email form: *Create account* (name, email, password, weight, optional FTP), *Sign in* and *Forgot password*. |
| `cloud/presence.ts` | Riding together: sends your position every 2 s and predicts the other riders' positions. |
| `cloud/sync.ts` | Syncs settings, workouts and routes; saves and reads rides and FTP history; feedback; leaderboards and ghosts; and the admin calls. |
| `cloud/recorder.ts` | Records one sample per second while moving, and writes `.tcx` files. |
| `cloud/achievements.ts` | Works out the 17 achievements from rides and FTP history. |
| `cloud/charts.ts` | Draws the bar charts, line charts and stat tiles in the profile. |
| `cloud/ui.ts` | The sign-in and password-reset dialogs, the profile tabs, the feedback dialog, and the admin dashboard. |

## Tests and tooling

The repository has no test files, no linter configuration and no Playwright setup. The build's type check is the main automated check. See [Testing](testing.md).
