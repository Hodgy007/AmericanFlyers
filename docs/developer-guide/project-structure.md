# Project structure

This page lists every file and folder in the repository, with a one-line summary of what each does.

## Top level

| Path | Purpose |
| --- | --- |
| `index.html` | The page markup: home page, top bar and ☰ menu, data blocks, workout, gear, draft and demo panels, status line, every dialog. |
| `package.json` | Scripts (`dev`, `build`, `preview`) and dependencies. |
| `vite.config.ts` | Vite config: relative base (`./`), the `vendor-three`, `vendor-neon` and `vendor-sentry` chunks, and Sentry source-map upload. |
| `tsconfig.json` | TypeScript config: strict mode, `noUnusedLocals`, and the `web-bluetooth` and `vite/client` types. |
| `README.md` | Features, browser support, local run instructions and the backend overview. |
| `CLAUDE.md` | Project notes for AI coding assistants: commands, preferences, deployment and the backend. |
| `db/schema.sql` | The database schema, policies, triggers, admin functions, and the riding-together, leaderboard and ghost functions. |
| `.gitignore` | Ignores `node_modules`, `dist` and `.DS_Store`. |
| `public/` | Static files served as-is. See below. |
| `dist/` | Build output. Generated by `npm run build`, and not tracked by git. |
| `docs/` | This documentation library. |

## `public/`

| Path | Purpose |
| --- | --- |
| `public/models/*.glb` | 3D models: landmarks (barn, farmhouse, windmill, diner, water tower, gas station, silos, covered bridge, start/finish gantry) and the rigged rider (`rider.glb`). |
| `public/models/README.md` | What each landmark model is and where it's placed. |
| `public/textures/asphalt.jpg` | Road surface texture. |
| `public/textures/grass.jpg` | Grass detail texture, multiplied over the land colors. |
| `public/images/hero*.jpg`, `hero*.mp4` | The home page hero (still and looping video, with smaller phone versions). |
| `public/images/hero-dog*.jpg`, `hero-dog*.mp4` | The second hero: a pit bull chasing the rider. The home page rotates between the two heroes (`heroRotator()` in `src/home.ts`; `?hero=dog` or `?hero=rider` pins one). |
| `public/icons/` | App icons (192, 512, maskable 512, Apple touch icon, favicon). |
| `public/audio/commentary/*.mp3` | The race commentator's 39 voice lines (generated with Higgsfield; `CLIPS` in `src/commentary.ts` says what each one says). |
| `public/manifest.webmanifest` | Makes the app installable: name, icons, full-screen display, colours. |
| `public/sw.js` | Service worker: network-first pages, cached build files, models and textures. Never caches Neon. |

## `src/`

| File | Purpose |
| --- | --- |
| `main.ts` | Entry point. Owns the ride state, runs the frame loop, controls the trainer, handles the top bar, ☰ menu and dialogs, saves rides, and wires up sign-in, riding together, ghosts, plans, sound, virtual shifting and drafting. |
| `lazy.ts` | Lazy loading helpers: `lazy()`, `use()`, `loadOnClick()`, `prefetchWhenIdle()`, `firstFrame`. See [Architecture](architecture.md#lazy-loading). |
| `home.ts` | The home page: hero (one of two, picked per visit), Google and email sign-up, and *Ride without an account*. |
| `drivetrain.ts` | The virtual drivetrain: automatic gears that keep leg speed in step with road speed, the 24 virtual-shifting gears, crank angle and bike rock. |
| `peloton.ts` | The computer-ridden pro teams: names and kits, paces, physics, the two-by-two paceline, and respawning at the finish. |
| `draft.ts` | Drafting: the drag saved at a given gap behind another rider (and how far across from their line), and the rider just ahead. |
| `steering.ts` | Your lane across the road: ← / → steps, key and button hold-to-repeat, and auto-steer into the draft. |
| `world/wind.ts` | The wind: per-stage speed and direction scaled by weather, gusts, head and cross components, the echelon shift. No DOM or Three.js. |
| `windUi.ts` | The wind chip in the status line. |
| `miniMap.ts` | The route mini-map (north-up or heading-up) with riders, ghost, finish, sprint and summit markers. |
| `climb.ts` | Climb detection from an elevation profile, and where you are relative to the next climb. |
| `climbUi.ts` | The climb preview card. |
| `atmosphereUi.ts` | The ☰ Menu → Time & weather dialog. |
| `peloton.ts` | The computer-ridden pro teams: names and kits, paces, physics, the two-by-two paceline, and respawning at the finish; and race mode (`startRace`, `makeRoster`, `RaceField`) that hands the field to the race engine. |
| `raceSim.ts` | The race engine: riders in groups, attacks, breaks, chases, cracks, merges, sprints, lines and points. No DOM or Three.js. |
| `race.ts` | The race you are riding: countdown, live panel numbers, jersey holders and results. |
| `raceUi.ts` | The 3-2-1, the live race panel, and the result tables. |
| `schedule.ts` | The daily event schedule as a pure function (client mirror of the SQL), countdown text and the join window. |
| `eventSession.ts` | Pure logic for scheduled events: the shared clock, `DropWatcher` for group rides, and merging real and computer-ridden results. |
| `eventsUi.ts` | The 🗓 Events dialog, the lobby bar and the finish card's event results. |
| `commentary.ts` | The race commentator: rate-limited voice lines (`Commentator`), the race-to-lines mapping (`RaceCommentary`) and the audio player. |
| `cloud/events.ts` | Event RPC calls and the server clock offset. |
| `tour.ts` | The Hell of the West tour: progress in `settings.tour`, classifications, `tourJersey()`, and "simulate this stage". |
| `tourUi.ts` | The tour dialog. |
| `draft.ts` | Drafting: the drag saved at a given gap behind another rider, and the rider just ahead. |
| `ghost.ts` | Replays a past whole-stage ride as a ghost, and formats race times. |
| `sound.ts` | Ride sounds made with Web Audio: wind, tyre hum, freewheel, crowds, beeps, shift clicks and the finish fanfare. |
| `plans.ts` | The training plans and their progress logic. |
| `plansUi.ts` | The training plans dialog. |
| `onboarding.ts`, `onboardingState.ts` | The three-step first-ride guide (lazy), and the tiny "has it been done" check that stays in the entry chunk. |
| `ridersUi.ts` | The 👥 button and the *Riding now* list, with the ride-on emoji buttons on each rider. |
| `rideOnsUi.ts` | Ride-ons in the app: sending (from 👥 and the **R** key), the toast for ones you get, the floating emoji, and pro riders replying. |
| `kit.ts` | Your kit (jersey, second colour, frame): the presets, validation, the kit string sent to the server, and `setTourJersey()` for tours. |
| `kitUi.ts` | The ☰ Menu → 🎨 *My kit* dialog. |
| `garage/catalogue.ts` | The store catalogue (items, prices, unlock rules, effects), loadout validation and `equipmentEffects()`. `scripts/gen-store-sql.mjs` prints the matching SQL seed. |
| `garage/style.ts` | The bike and clothing style names the 3D model understands and the `;f=tron;…` codes in the kit string. |
| `garage/progression.ts`, `garage/challenges.ts`, `garage/md5.ts` | The level curve, wallet parsing, and the weekly challenge pool and pick (mirrors the database). |
| `garage/effects.ts` | What an item does in watts and seconds, from the ride's physics. |
| `garage/store.ts`, `garage/garage.ts`, `garage/api.ts` | Item states and equipping, the controller (wallet, loadout, rewards) and the database calls. |
| `garage/garageUi.ts`, `garage/preview.ts` | The Garage dialog and its turntable renderer. |
| `garage/shareCard.ts`, `garage/shareUi.ts`, `garage/shareButton.ts` | The share card canvas, building its data, and the Share buttons (the first two load on the first press). |
| `world/bikeParts.ts` | Wheels, the Tron glow (`updateGlow`), helmets, and the jersey pattern and sock shader. |
| `leaderboardUi.ts` | The 🏆 leaderboard dialog and *Race* buttons. |
| `style.css` | All styles, including the layout for phones. |
| `hud.ts` | The 24 data-block fields, the HUD tiles, and the data-block chooser dialog. |
| `settings.ts` | The `Settings` type, its defaults, and loading and saving to `localStorage`. |
| `stats.ts` | Ride statistics: averages, normalized power, TSS, best efforts (5 s, 1, 5 and 20 min), max values and time in zone. |
| `zones.ts` | Heart-rate and power zone definitions, zone lookup, and the zone bar display. |
| `physics.ts` | The power-to-speed model: gravity, rolling resistance, air drag (reduced in a draft), drivetrain loss and momentum. |
| `course.ts` | The current stage's road: elevation, grade, heading and a cached centerline. |
| `stages.ts` | Built-in stages (Heartland Rollers, Route 66 Flats, the three Hell of the West tour stages, Alpe d'Huez, Stelvio Pass, Mont Ventoux, Col du Tourmalet, Monte Zoncolan), the climb builder, landmark kinds, and the stage list. |
| `profile.ts` | The elevation strip, and the grade-to-color function. |
| `ble/trainer.ts` | Trainer connection: FTMS and Cycling Power, parsing, and the control point (grade with a wind-resistance factor, and target power). |
| `ble/heartRate.ts` | Heart-rate strap connection and parsing. |
| `ble/remembered.ts` | Remembered devices (`americanflyers.devices` in `localStorage`), the no-chooser reconnect helpers (`getDevices`, `watchAdvertisements`), the retry schedule (`Reconnector`) and the menu labels. Pure and feature-detected; unit-tested. |
| `devicesUi.ts` | Trainer and heart-rate connection life cycle: the ☰ Menu items, Forget, the Settings list, the "Reconnect" banner, reconnect on load and after a drop. `main.ts` only receives change callbacks. |
| `routes/gpx.ts` | Parses GPX files, and turns a route into a stage. |
| `routes/library.ts` | Saved GPX routes in `localStorage`, and the full stage list (built-in plus uploaded). |
| `workouts/model.ts` | Workout types, expansion into steps, TSS estimation, the ten built-in workouts, and the zone colors. |
| `workouts/player.ts` | Runs a workout: the clock, the current target, the intensity, pause and skip. |
| `workouts/files.ts` | Imports `.zwo`, `.erg` and `.mrc` files, and exports `.zwo`. |
| `workouts/library.ts` | The rider's saved workouts in `localStorage`, and the built-ins. |
| `workouts/graph.ts` | Draws a workout's shape, with the elapsed time and the power trace. |
| `workouts/ui.ts` | The workout library and the workout creator dialogs. |
| `world/world.ts` | The Three.js renderer, lights, cameras, and the per-frame scene update. |
| `world/others.ts` | Other riders and ghosts on the road: models, name tags, lanes, smoothing and passing. |
| `world/terrain.ts` | Ground tiles, height and color, and the scattered trees. |
| `world/road.ts` | Road chunks, distance markers, hairpin plaques, and the finish line. |
| `world/landmarks.ts` | Loads the landmark models and places them along the road. |
| `world/rider.ts` | The bike and rider: a built-in fallback, and the rig that poses the rigged rider (shared model, cloned per rider; frame colours and ghost look). |
| `world/sky.ts` | The sky dome (with stars and moon), the mountain ring, and the clouds, all tinted at runtime by the atmosphere. |
| `world/atmosphere.ts` | Time of day and weather: keyframed looks, sun and moon, ambient light, fog, exposure, front light, wet road. |
| `world/rain.ts` | Rain: GPU-animated streaks in a box that follows the camera. |
| `world/noise.ts` | Deterministic noise (value noise and fractal noise), a seeded random generator, and `smoothstep`. |
| `cloud/client.ts` | The Neon client, configured from the default endpoints or `VITE_` variables, loaded on demand through a recording proxy. |
| `cloud/account.ts` | The signed-in account: session restore, Google sign-in, email sign-up and sign-in, password reset, sign-out and rename. |
| `cloud/emailAuth.ts` | The email form: *Create account* (name, email, password, weight, optional FTP), *Sign in* and *Forgot password*. |
| `cloud/presence.ts` | Riding together: sends your position and kit every 2 s and predicts the other riders' positions. |
| `cloud/rideOns.ts` | Ride-ons: `send_ride_on()` and the 4 s poll of `my_ride_ons()`. |
| `cloud/sync.ts` | Syncs settings, workouts and routes; saves and reads rides and FTP history; feedback; leaderboards and ghosts; and the admin calls. |
| `cloud/recorder.ts` | Records one sample per second while moving, and writes `.tcx` files. |
| `cloud/achievements.ts` | Works out the 17 achievements from rides and FTP history. |
| `cloud/charts.ts` | Draws the bar charts, line charts and stat tiles in the profile. |
| `cloud/verification.ts` | Email verification codes: pure helpers (code cleaning, resend timer, error wording) and the two SDK calls. |
| `cloud/codeEntry.ts`, `cloud/verifyBanner.ts` | The 6-digit code box (used in the email form and the profile banner). |
| `cloud/privacy.ts`, `cloud/accountTab.ts` | "Download my data" and "Delete my account", and the profile tab that offers them. |
| `privacyUi.ts`, `privacyText.ts`, `rideIntegrity.ts` | The Privacy dialog (any `data-privacy` element opens it; the text is lazy); which rides may be on leaderboards. |
| `cloud/accountBar.ts` | The 👤 button and admin button in the top bar, and the entry points that load `cloud/ui.ts`. |
| `cloud/ui.ts` | The sign-in and password-reset dialogs, the profile tabs, the feedback dialog, and the admin dashboard (lazy). |

## Tests and tooling

The repository has no linter configuration. `tests/unit/` holds the Vitest unit tests, `tests/e2e/` the Playwright smoke test, and `.github/workflows/ci.yml` runs them with the build on every pull request. See [Testing](testing.md).
